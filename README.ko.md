# 이명(異名) yiming

**중국 사서 속 한자에 가려진 외래 이름을 드러냅니다.**

[English](README.md) · [简体中文](README.zh-CN.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [Tiếng Việt](README.vi.md)

![禄山 위에 소그드어 원형 Roxšan이 표시되고, 툴팁에 이름과 '安'씨 성의 유래가 나온다](docs/img/anlushan.png)

## 왜 만들었나

중국 사서는 외국의 인명·민족명·지명을 한자로 적었고, 그 때문에 이름의 원래 모습이 가려졌습니다.

- **원래 이름이 사라집니다.** 반란을 일으킨 安禄山의 이름 '禄山'은 소그드어 *Roxšan*('빛나는')으로, 그리스어 *Roxana*와 같은 어원입니다. 현대 중국어로 *Lùshān*이라고 읽으면 아무것도 보이지 않지만, 당나라 때 발음 *luk-ʂɛn*으로 읽으면 바로 드러납니다.
- **한 이름, 여러 표기.** 오이라트는 시대에 따라 斡亦剌·瓦剌·厄鲁特·卫拉特로 적혔습니다. 오스만 제국은 명대에는 鲁迷(Rūm, '로마'), 청대에는 控噶尔, 이후에는 土耳其입니다.
- **후대 편찬이 더 어지럽혔습니다.** 『사고전서(四库全书)』를 편찬할 때 건륭제는 요·금·원 세 왕조 역사서의 외래 이름을 거의 모두 고쳐 적게 했습니다(伯颜→巴延, 脱脱→托克托, 拔都→巴图). 그런데 인터넷의 전자 텍스트는 대부분 사고전서본입니다.

yiming은 사서를 읽고 **각 외래 이름 위에 원어 형태를 적어 주며**, 어족별로 색을 칠합니다. 같은 이름의 여러 표기는 하나로 통일해 보여 주고, 건륭 때의 개역도 되돌립니다. **원문은 결코 바꾸지 않습니다.** 그 구절이 실제로 쓴 표기는 항상 옆에 남아 있습니다.

## 지금 할 수 있는 일

- **읽기 화면.** 외래 이름마다 다음이 붙습니다.
  - 위쪽: 원형(*Roxšan*, *Bayan*, *Rūm*)
  - 색: 어족(12개)
  - 밑줄: 판정의 확실성
  
  마우스를 올리면 언어, 뜻, 출전, 다른 표기, 같은 대상의 다른 이름을 볼 수 있습니다.
- **시대별 발음.** 이름이 적힌 시대의 발음으로 비교합니다.
  - 한~당: 중고음(『절운(切韵)』)
  - 송~명: 근고 관화 근사
  - 청: 청대 관화 근사
  
  잘 알려진 음역 관습도 반영했습니다. 예를 들어 당대에는 외국어의 *-r/-l*을 *-t* 운미로 옮겼습니다(阙 = *kül*).
- **이십사사에 그치지 않습니다.** Kanripo(약 9,000종) 텍스트를 내려받고, 책의 시대에 맞는 발음 체계를 자동으로 고릅니다.
- **사고전서본 복원.**
  - 『흠정요금원삼사국어해(钦定辽金元三史国语解)』(약 7,400쌍)를 이용합니다.
  - 같은 책의 두 판본을 한 글자씩 대조합니다(『원사』 본기에서 약 3,600쌍).
  - 하나의 개역 표기가 여러 옛 이름을 대신한 경우에는 추측하지 않고, 표시를 붙여 후보를 보여 줍니다.
- **책 사이트.** 책 한 권을 작은 웹사이트로 만듭니다.
  - 권마다 한 페이지
  - 권별 외래 이름의 양과 어족 구성을 막대로 보여 주는 목차
  - 각 이름에서 등장하는 권으로 연결되는 이름 색인
- **발견 도구.**
  - 책 속 모든 음역 이름의 목록을 만듭니다.
  - 발음은 비슷하지만 표기가 다른 이름을 찾습니다(이른바 '한 사람에 두 열전'의 후보).
  - 선택 사항으로, 원형을 모르는 이름에 대해 LLM에게 후보를 제안받습니다. 시대 발음과 맞는 제안만 남깁니다.
- **측정된 정확도.** 평가 명령으로 참·거짓 판정이 각각 얼마나 음성 검증을 통과하는지 확인할 수 있습니다([정확도](#정확도) 참조).

## 빠른 시작

### 1. 설치

Python 3.8 이상이 필요하며, 외부 패키지는 필요 없습니다.

```bash
git clone https://github.com/<계정>/yiming.git
cd yiming
python yiming.py setup          # 이체자 표 생성 (인터넷 연결 1회 필요)
```

선택 사항:

| 패키지 | 용도 |
|---|---|
| `pypinyin` | 운서에 없는 글자 처리 |
| `anthropic` | `propose` 명령 |
| `opencc` | `mc_table.json` 재생성 |

### 2. 텍스트 준비

둘 중 하나, 또는 둘 다 쓸 수 있습니다.

```bash
# (a) hunterhug/china-history의 이십사사 (약 250MB)
git clone --depth 1 https://github.com/hunterhug/china-history.git corpus

# (b) Kanripo의 아무 책이나, 제목 또는 KR 번호로
python yiming.py fetch 资治通鉴 --corpus corpus --juan 214
python yiming.py fetch 大唐西域记 --corpus corpus
```

### 3. 읽기

```bash
# 한 권 -> 한 페이지
python yiming.py read corpus/旧唐书/列传/第一百五十章-卷一百五十-原文.html -o anlushan.html

# 책 전체 -> 둘러볼 수 있는 사이트 (출력 이름에 .html을 붙이지 않음)
python yiming.py read corpus/元史 -o yuan_site
```

브라우저로 HTML을 엽니다. [`samples/`](samples/)에 완성된 예시가 있습니다.

## 화면 보는 법

**이름 위:** 원어 형태(이탤릭). 언어만 알고 원형을 모를 때는 ‹Khitan›처럼 표시됩니다.

**색 = 어족**

| 어족 | 예 |
|---|---|
| 이란어파(소그드어, 박트리아어, 파르티아어, 호탄 사카어, 페르시아어) | 禄山 *Roxšan*, 粟特 *Soγd*, 安息 *Aršak*, 哈烈 *Herāt* |
| 튀르크어족 | 突厥 *Türk*, 可汗 *qaγan*, 回纥 *Uyγur*, 鲁迷 *Rūm* |
| 몽골어족 | 帖木儿 *Temür*, 拔都 *ba'atur*, 斡罗思 *Orus* |
| 준몽골어(거란어, 선비어) | 契丹 *Kitan*, 拓跋 *Tabγač*, 耶律 |
| 퉁구스어족(여진어, 만주어) | 女真 *Jürchen*, 勃极烈 *bogile*, 贝勒 *beile* |
| 티베트어 | 喇嘛 *bla ma*, 拉萨 *Lha sa* |
| 인도어파(산스크리트어, 팔리어) | 佛陀 *Buddha*, 阿罗汉 *arhat*, 鸠摩罗什 |
| 드라비다어족 | 古里 *Kōḻikkōṭ*(캘리컷), 柯枝 *Kochi* |
| 셈어족(시리아어, 아랍어) | 移鼠 *Išoʿ*(예수), 默德那 *al-Madīna* |
| 오스트로네시아어족 | 满剌加 *Melaka*, 爪哇 *Jawa*, 吕宋 *Luzon* |
| 유럽어 | 和兰 *Holland*, 利玛窦 *Matteo Ricci* |
| 기타 / 미상 | 勃律 *Bolor*; 회색은 원형을 아직 모른다는 뜻 |

**밑줄 = 판정의 확실성**

| 밑줄 | 의미 |
|---|---|
| 실선 | 정리된 어휘표의 판정(출전 있음) |
| 파선 | 음성 검증을 통과한 LLM 제안(출전은 아직 미확인) |
| 회색 점선 | 음역처럼 보이지만 원형 미상 |
| 회색 물결선 | 하나의 사고전서 개역 표기가 여러 옛 이름을 대신한 경우. 마우스를 올리면 후보가 보임 |

**이름 뒤의 작은 회색 글자:** 그 구절이 실제로 쓴 표기. 이름을 통일 표기로 보여 줄 때 나타납니다.

**툴팁**(마우스를 올리거나 키보드 Tab): 언어, 뜻, 출전, 다른 표기, 같은 대상의 다른 이름(鲁迷 ↔ 控噶尔 ↔ 土耳其). 당대 사서에서 이름 앞에 安·康·石·米·何·史·曹가 있으면, 그 성이 가리키는 소그드 도시도 알려 줍니다.

## 기능 상세

### 시대별 발음과 음성 비교

각 글자의 『절운』 음운 지위는 nk2028의 `qieyun` 데이터(CC0)에서 가져옵니다. 이름은 음류의 열(성모류·모음류·운미)로 바뀝니다. 예를 들어 禄山은 `LuK SaN`, *Roxšan*은 `RuH SaN`입니다.

두 이름, 또는 이름과 로마자로 적은 원형을 가중 편집 거리로 비교합니다. 잘 알려진 음역 관습은 감점이 작습니다.

- *l* ↔ *r*
- *k* ↔ *x/h*
- 당대에 외국어 *-r/-l*을 *-t*로 옮긴 것
- 서북 방언의 비음 성모 탈비음화. 그래서 默이 *b-*를 나타낼 수 있습니다(默啜 = *Bäg Čor*).
- 어말 자음 생략(颉利 = *Illig*)

| 체계 | 대상 | 주요 규칙 |
|---|---|---|
| `mc` | 한~당·오대 사료 | 『절운』 성모. *-p -t -k -m -n -ŋ* 운미 유지 |
| `om` | 송·요·금·원·명 | 입성 운미 소실. 疑모는 영성모. 日모 ≈ *r* |
| `qm` | 청 | `om`과 같으나 *-m*이 *-n*에 합류. 첨음·단음 구별은 유지(청대 만주어 음사 관행) |

체계는 편찬자의 시대가 아니라 **사료의 시대**로 정합니다. 『명사』는 청대에 명대 자료로 편찬했으므로 `om`을 씁니다. 선택은 먼저 서명 대응표를 보고, 그다음 내려받을 때 기록한 왕조를 봅니다. `--scheme`으로 직접 지정할 수도 있습니다.

**시대 필터:** 어휘표 항목은 가장 이른 표기보다 오래된 책에서는 일치시키지 않습니다. 그래서 古里는 명대 문헌에서는 캘리컷이지만 『구당서』에서는 아닙니다.

### 이름: 어휘표, 표기, 실체

| 표 | 내용 |
|---|---|
| `lexicon.tsv` | 정리된 123개 항목: 원형, 언어, 어족, 뜻, 한자 표기, 출전 |
| `equivalence.tsv` | 같은 이름의 여러 표기를 하나로 통일해 표시 |
| `entity` 열 | 한 대상의 서로 다른 **이름**. 연결만 하고 합치지는 않음 |

간체·번체 모두 일치합니다. 약 21,000개의 이체자(竒 → 奇)를 정자로 맞춥니다.

### 다른 책: Kanripo

```bash
python yiming.py fetch KR2a0036 --corpus corpus --juan 1-47 --name 元史_四库
```

텍스트는 `corpus/<서명>/NNN.txt`로 정리되고, 편찬자의 왕조는 `meta.json`에 기록됩니다. 사고전서본에는 구두점이 없으므로 쪽 단위로 문단을 나눕니다.

### 사고전서본: 건륭 개역 되돌리기

1. `guoyujie`는 『삼사국어해』에서 '건륭 표기 → 옛 표기'를 뽑습니다. 건륭이 주장한 '만주어·몽골어 뜻'은 견강부회가 많아 **쓰지 않습니다**.
2. `align A B`는 같은 책의 두 판본을 권별로 대조하여, 서로 다르고 음역처럼 보이는 짧은 구간을 모읍니다. 사고전서 쪽 표기는 옛 판본에 나오지 않아야 합니다.
3. Kanripo에서 받은 책을 읽을 때 개역은 자동으로 복원되고, 사고전서 표기는 회색 작은 글자로 남습니다. 하나의 개역 표기가 여러 옛 이름을 대신한 경우(俄罗斯가 斡罗思 *Orus*와 兀鲁思 *ulus* 모두를 대신함)에는 그대로 두고 물결선을 그으며, 툴팁에 후보와 횟수를 보여 줍니다.
4. 청대 문헌은 원래 그 표기로 쓰였으므로 **복원하지 않습니다**.

![사고전서본 『원사』: 巴图가 拔都(ba'atur)로 복원되고, 사고전서 표기는 회색으로 남는다](docs/img/siku.png)

### 책 사이트

`read 책폴더 -o 출력폴더`는 다음을 만듭니다.

- `index.html`: 권마다 어족별 색 막대가 있는 목차
- 권마다 한 페이지(이전·다음 링크)
- `names.html`: 모든 이름을 어족별로 묶고, 횟수와 권 링크를 붙임

『구당서』 201권은 약 6초면 만들어집니다.

### 발견 도구

| 명령 | 기능 |
|---|---|
| `scan` | 책 속 모든 음역 이름의 표: 횟수, 상태, 원형, 어족, 처음 나온 문맥 |
| `twins` | 발음은 비슷하고 표기가 다른 이름(예: 萧得里底 / 萧迭里得). 결론이 아니라 검토 목록 |
| `propose`(실험적) | 미상의 이름을 시대 발음, 문맥 한 줄과 함께 LLM에 보냅니다. 평범한 한어로 판정된 것은 걸러집니다. 제안된 원형은 음성 검증(≥ 0.60)을 통과해야 남고, 파선으로 표시됩니다. 답은 캐시됩니다. **지금까지 모의 응답으로만 시험했습니다.** |

### 정확도

`python yiming.py eval gold_pairs.tsv --corpus corpus`의 결과입니다(`samples/eval.txt`).

**한자 표기 vs 원형:** 어휘표의 참 쌍 166개, 거짓 쌍 19,920개.

| 문턱값 | 참 판정 유지 | 거짓 판정 혼입 |
|---|---|---|
| 0.55 | 78% | 4.0% |
| **0.60**(`propose` 기본값) | 72% | 2.2% |
| 0.70 | 54% | 0.75% |

**표기 vs 표기:** 이미 알려진 이표기 19쌍, 무작위 이름 쌍 2만 개. 0.80에서 재현율 79%, 쌍당 오탐률 0.17%.

음이 맞는다는 것은 거르는 장치일 뿐, 증명이 아닙니다.

## 명령 목록

| 명령 | 용도 |
|---|---|
| `read 파일또는폴더 -o 출력` | 읽기 화면. `.html`이면 한 페이지, 아니면 책 사이트. 옵션: `--display latin`, `--known-only`, `--unknown-mean`, `--scheme`, `--siku on/off` |
| `find 단어 --corpus 폴더` | 그 단어가 나오는 파일 |
| `fetch 서명또는번호 --corpus 폴더` | Kanripo에서 내려받기. `--juan 1-10`, `--name` |
| `setup` | `variants.json`(이체자 표) 생성 |
| `guoyujie` | 『삼사국어해』에서 건륭 개역 추출 |
| `align A폴더 B폴더 -o 파일` | 두 판본을 대조해 바뀐 이름 수집 |
| `scan`, `twins`, `propose` | 발견 도구(위 참조) |
| `key 이름`, `match A B` | 고음 보기, 두 이름(또는 이름과 원형) 비교 |
| `train --corpus 폴더` | 음역에 자주 쓰이는 글자를 다시 학습 |
| `eval gold_pairs.tsv` | 정확도 보고 |

중국어로 된 자세한 문서는 [`docs/`](docs/)에 있습니다(한 페이지 버전: `docs/指南.html`).

## 한계

- **이름의 언어는 문화적 배경의 증거이지, 혈통의 증명이 아닙니다.** 다른 단서(성, 출신지, 사서가 '胡'라고 부름)와 맞으면 강한 증거입니다. 외래 이름이 유행한 시대(원대 한인의 몽골식 이름, 승려의 산스크리트 법명)에는 약합니다.
- **범위는 어휘표에 달려 있습니다.** 『원사』에서 약 930개의 음역 이름이 검출되지만, 정리된 어휘표에는 약 50개뿐입니다. 나머지는 `propose`나 사람이 보충하기 전까지 회색으로 남습니다.
- **검출은 통계적입니다.** 당대 문헌에서는 일부 한어 단어(补阙)가 잘못 검출됩니다.
- **사고전서본 복원은 완벽하지 않습니다.** 놓치는 개역이 있고, 대조 과정에서 이웃 글자가 이름에 섞이기도 합니다.
- **`propose`는 아직 실제 LLM 응답으로 시험하지 않았습니다.**
- **어휘표 출전 중 상당수가 그냥 "standard"(통설)로 되어 있습니다.** 점차 구체적인 문헌으로 바꿔야 합니다.
- **『청사고』는 Kanripo 목록에는 있지만 본문이 공개되어 있지 않습니다.**

## 현재 범위를 넘어 쓰려면

### 현재 범위

- **텍스트:** 이십사사(hunterhug)와 Kanripo의 책들. 한~청의 한문 사료입니다.
- **발음:** 『절운』에서 유도한 세 체계 `mc`·`om`·`qm`
- **이름:** 내륙아시아, 남아시아, 서아시아 이름 위주이며, 일부 해양·유럽 이름이 있습니다. 12개 어족으로 나눕니다.

### 확장 점검표

1. **텍스트.** 순수 텍스트를 `corpus/<서명>/*.txt`에 문단당 한 줄로 넣습니다(`.html`도 가능). 새 출처라면 작은 변환기를 만듭니다. `corpora.clean_mandoku`를 참고하세요.
2. **시대.** `origin.py`의 `BOOK_SCHEME`에 서명을 추가하거나, 책의 `meta.json`에 `"scheme": "mc"`를 넣습니다.
3. **발음.** `mc`·`om`·`qm` 중 맞는 것이 없으면 새 체계를 추가합니다.
   - `yiming.py`의 `syllable()`(절운 기반 규칙) 또는 `Phon.char_sylls()`(다른 독음 자료)를 확장해, 글자마다 (성모류, 운미류, 모음류)를 돌려주게 합니다.
   - 체계 이름을 명령행 선택지와 `origin.py`의 `ERA`에 추가합니다.
   - 그 언어에 전형적인 음 대응이 있으면 `yiming.py`의 `SUB`·`INDEL`에 추가합니다.
4. **이름.** `lexicon.tsv`에 실제 출전과 함께 항목을 추가합니다. 새 어족은 `origin.py`의 `FAMILIES`와 CSS 색에 추가합니다.
5. **표기.** 같은 이름의 이표기는 `equivalence.tsv`에 넣습니다. 사고전서처럼 이름을 고친 판본이 있다면, 고치지 않은 판본과 `align`으로 대조합니다.
6. **검출.** 새 텍스트로 `train --corpus 폴더`를 실행합니다. 그 전통 고유의 음역용 글자가 있으면 `origin.py`의 `SEED_CHARS`에 추가합니다.
7. **정확도 확인.** 그 분야의 확인된 대응을 `gold_pairs.tsv`에 넣고 `eval`을 실행합니다. 직접 측정한 문턱값만 믿으세요.
8. **LLM 제안(선택).** `origin.py`의 `PROMPT`를 새 분야에 맞게 고칩니다.

### 경우별 안내

| 범위 | 바꿀 것 |
|---|---|
| **한국의 한문 사서**(삼국사기, 고려사, 조선왕조실록) | 여진·몽골·일본 이름은 조선 문인이 음사한 경우가 많습니다. 한국 한자음 체계를 추가합니다(Unicode Unihan 데이터베이스의 `kHangul` 필드가 독음을 제공. 한국 한자음 *-l*은 중고음 *-t*에 대응). 한국어족·일본어족 등도 추가합니다. |
| **일본의 한문 사서**(일본서기, 속일본기 등) | 한반도·아이누 이름이 한자로 표음되며, 만요가나와 비슷한 경우가 많습니다. 일본 한자음 체계를 추가합니다(Unihan `kJapaneseOn`. *-tsu/-chi* ↔ *-t*, *-ku/-ki* ↔ *-k*). |
| **베트남의 한문 사서**(대월사기전서, 흠정월사통감강목) | 참파·크메르·타이 이름이 나옵니다. 한월음 체계를 추가합니다(Unihan `kVietnamese`. *-t, -c, -p* 유지). 오스트로아시아어족·타이카다이어족 등도 추가합니다. |
| **불전**(CBETA) | TEI XML 변환기를 만듭니다. 후한대의 초기 음역(浮屠 등)은 『절운』보다 이르므로, 발표된 재구에 따라 상고음 또는 후한음 체계를 추가합니다. |
| **더 이른 시대**(『사기』·『한서』의 흉노, 서역) | 위와 같이 절운 이전 체계가 필요합니다. 원어에 대해 알려진 것이 적어 정확도는 낮을 것입니다. |
| **청말·민국 문헌** | 서양 이름은 관화, 또는 광둥어·민남어로 음사되었습니다. 병음 기반 체계를 추가하고, 남방 문헌에는 광둥어 체계(Unihan `kCantonese`)를 씁니다. |
| **이름을 고친 다른 판본** | 어떤 두 판본이든 `align`으로 대조할 수 있습니다. |

## 데이터 출처와 라이선스

[DATA_SOURCES.md](DATA_SOURCES.md)를 보세요.

- 코드는 MIT 라이선스입니다.
- `mc_table.json`은 nk2028 qieyun 데이터(CC0)에서 왔습니다.
- 예시와 사고전서 개역표는 Kanripo 텍스트에서 왔습니다. 재사용 전에 Kanripo의 조건을 확인하세요.
- `variants.json`은 cjkvi 이체자 표로 로컬에서 만들며, 저장소에는 넣지 않습니다.
- hunterhug의 텍스트는 이 저장소에 재배포하지 않습니다.

## 기여

잘못되었거나 빠진 판정을 발견하면 다음 세 가지를 알려 주세요.

1. 서명과 권
2. 해당 문장
3. 옳다고 생각하는 것과 **그 출전**

이 세 가지가 있으면 누구나 검증하고 고칠 수 있습니다. 실제 출전이 있는 `lexicon.tsv` 수정 요청을 환영합니다.
