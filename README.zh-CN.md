# 异名 yiming

**让中国史书里被汉字遮住的外族名字"现形"。**

[English](README.md) · [简体中文](README.zh-CN.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [Tiếng Việt](README.vi.md)

![禄山上方标出粟特语原形 Roxšan；悬停框说明名字和"安"姓的来历](docs/img/anlushan.png)

## 为什么做这个

中国史书用汉字记录外族的人名、族名和地名，名字原来的样子就被遮住了。

- **原名消失了。** 安禄山的"禄山"原是粟特语 *Roxšan*，意为"光明"，和希腊语 *Roxana*（罗克珊娜）同源。用普通话读 *Lùshān*，什么也看不出来；按唐代读音 *luk-ʂɛn*，就一目了然了。
- **同一个名字，很多写法。** 卫拉特蒙古在不同时代写作斡亦剌、瓦剌、厄鲁特、卫拉特。奥斯曼帝国在明代叫"鲁迷"（Rūm，意为"罗马"），清代叫"控噶尔"，后来叫"土耳其"。
- **后人改得更乱。** 修《四库全书》时，乾隆下令把辽、金、元三史里几乎所有的外族名字都改译了一遍：伯颜→巴延，脱脱→托克托，拔都→巴图。而网上的电子古籍大多是四库本。

yiming 读入一部史书，**在每个外族名字上方写出它的原语言形式**，并按语系着色。它把同一个名字的不同写法统一成一种显示，并还原乾隆的改译。**原文从不被篡改**：书里实际用的写法始终保留在旁边。

## 现在能做什么

- **阅读页面。** 每个外族名字上方有原形（*Roxšan*、*Bayan*、*Rūm*），用颜色表示语系（12 个语系），用下划线表示认定的可信程度。鼠标悬停可以看到语言、意思、出处、其他写法，以及同一事物的其他名称。
- **按时代的读音。** 用写下名字时的读音来比较：
  - 汉唐用中古音（《切韵》）；
  - 宋至明用近古官话（近似）；
  - 清代用清代官话（近似）。
  
  程序还编入了常见的对音习惯，例如唐代用 *-t* 韵尾对译外语的 *-r/-l*（阙 = *kül*）。
- **不只二十四史。** 可以从 Kanripo 开放古籍库（约九千种书）下载任何一部书，并按书的时代自动选择读音方案。
- **还原四库本改译。** 利用《钦定辽金元三史国语解》（约 7,400 对），以及同一部书两个版本的逐字比对（《元史》本纪约 3,600 对），把乾隆的改译还原成旧译。一个改译对应多个旧名时，程序不替你猜：标出来，并列出候选。
- **书站。** 一整部书可以生成一个小网站：每卷一页；目录页用彩色横条显示每卷外族名字的多少和语系构成；名字索引把每个名字链接到它出现的各卷。
- **发现工具。**
  - 列出一部书里所有像音译的名字。
  - 找出读音相近、写法不同的名字（可能的"一人两传"）。
  - 可选：让大语言模型（LLM）为未知名字提出原形。只有读音和时代读音对得上的提议才保留。
- **准确率可以测量。** 评测命令会报告真、假认定各有多少能通过读音核验（见[准确率](#准确率)）。

## 快速开始

### 1. 安装

需要 Python 3.8 以上，不需要任何第三方库。

```bash
git clone https://github.com/<你的账号>/yiming.git
cd yiming
python yiming.py setup          # 生成异体字表（只需联网一次）
```

可选：

| 库 | 用途 |
|---|---|
| `pypinyin` | 韵书里查不到的生僻字 |
| `anthropic` | `propose` 命令 |
| `opencc` | 重新生成 `mc_table.json` |

### 2. 准备史书文本

两种来源任选，或者都用。

```bash
# (a) hunterhug/china-history 的二十四史（约 250MB）
git clone --depth 1 https://github.com/hunterhug/china-history.git corpus

# (b) Kanripo 上的任何一部书，用书名或编号
python yiming.py fetch 资治通鉴 --corpus corpus --juan 214
python yiming.py fetch 大唐西域记 --corpus corpus
```

### 3. 阅读

```bash
# 一卷 -> 一个网页
python yiming.py read corpus/旧唐书/列传/第一百五十章-卷一百五十-原文.html -o 安禄山传.html

# 一整部书 -> 一个可以浏览的书站（输出名不带 .html）
python yiming.py read corpus/元史 -o 元史_阅读
```

用浏览器打开生成的网页。[`samples/`](samples/) 里有做好的示例。

## 页面怎么看

**名字上方：** 斜体的原语言形式。只知道语言、不知道原形时，显示为 ‹Khitan›。

**颜色 = 语系**

| 语系 | 例子 |
|---|---|
| 伊朗语族（粟特、巴克特里亚、帕提亚、于阗塞语、波斯） | 禄山 *Roxšan*、粟特 *Soγd*、安息 *Aršak*、哈烈 *Herāt* |
| 突厥语族 | 突厥 *Türk*、可汗 *qaγan*、回纥 *Uyγur*、鲁迷 *Rūm* |
| 蒙古语族 | 帖木儿 *Temür*、拔都 *ba'atur*、斡罗思 *Orus* |
| 类蒙古语（契丹、鲜卑） | 契丹 *Kitan*、拓跋 *Tabγač*、耶律 |
| 通古斯语族（女真、满） | 女真 *Jürchen*、勃极烈 *bogile*、贝勒 *beile* |
| 藏语 | 喇嘛 *bla ma*、拉萨 *Lha sa* |
| 印度语族（梵语、巴利语） | 佛陀 *Buddha*、阿罗汉 *arhat*、鸠摩罗什 |
| 达罗毗荼语 | 古里 *Kōḻikkōṭ*（卡利卡特）、柯枝 *Kochi* |
| 闪米特语族（叙利亚语、阿拉伯语） | 移鼠 *Išoʿ*（耶稣）、默德那 *al-Madīna* |
| 南岛语 | 满剌加 *Melaka*、爪哇 *Jawa*、吕宋 *Luzon* |
| 欧洲语言 | 和兰 *Holland*、利玛窦 *Matteo Ricci* |
| 其他 / 未知 | 勃律 *Bolor*；浅灰表示原形尚未查明 |

**下划线 = 可信程度**

| 下划线 | 含义 |
|---|---|
| 实线 | 人工整理的词表中的认定，有出处 |
| 虚线 | 通过了读音核验的 AI 提议，出处尚未核实 |
| 浅灰点线 | 像音译，但原形未知 |
| 浅灰波浪线 | 四库本的改译，但它替换过不止一个旧名；悬停可看候选 |

**名字后面的灰色小字：** 这段文字实际用的写法。程序把名字显示成统一写法时才会出现。

**悬停框**（鼠标悬停，或用键盘 Tab 键）：语言、意思、出处、其他写法，以及同一事物的其他名称（鲁迷 ↔ 控噶尔 ↔ 土耳其）。唐代史书中，名字前面若是安、康、石、米、何、史、曹，还会提示这个姓对应的粟特城市。

## 功能详解

### 按时代的读音和读音比较

每个字的《切韵》音韵地位来自 nk2028 的 `qieyun` 数据（CC0）。名字被转成"音类串"：声母类、元音类、韵尾。例如"禄山"是 `LuK SaN`，*Roxšan* 是 `RuH SaN`。

两个名字之间，或名字和拉丁转写的原形之间，用加权编辑距离比较。常见的对音习惯只扣很少的分：

- l ↔ r；
- k ↔ x/h；
- 唐代以 *-t* 对 *-r/-l*；
- 西北方音鼻音声母去鼻化，所以"默"可以对 *b-*（默啜 = *Bäg Čor*）；
- 外语词尾辅音省略（颉利 = *Illig*）。

| 方案 | 用于 | 主要规则 |
|---|---|---|
| `mc` | 汉唐五代的史料 | 《切韵》声母；保留 *-p -t -k -m -n -ŋ* 韵尾 |
| `om` | 宋辽金元明 | 入声韵尾消失；疑母变零声母；日母近 *r* |
| `qm` | 清代 | 同 `om`，另外 *-m* 并入 *-n*；保留尖团之分（清人音写满文时就是这样做的） |

方案按**史料的时代**选择，而不是编者的时代。例如《明史》是清人据明代史料编的，所以用 `om`。程序先查书名对照表，再看下载时记录的朝代；也可以用 `--scheme` 手动指定。

**时代过滤：** 词表条目不会在比它最早写法更早的书里匹配。所以"古里"在明代文献里是卡利卡特，在《旧唐书》里不是。

### 名字：词表、写法、实体

| 表 | 内容 |
|---|---|
| `lexicon.tsv` | 123 条人工整理的条目：原形、语言、语系、释义、汉字写法、出处 |
| `equivalence.tsv` | 同一个名字的不同写法，统一成一种显示 |
| `entity` 列 | 同一事物的不同**名字**：互相链接，但不合并 |

简体、繁体都能匹配。约两万一千个异体字形（竒 → 奇）会被归并。

### 其他史书：Kanripo

```bash
python yiming.py fetch KR2a0036 --corpus corpus --juan 1-47 --name 元史_四库
```

文本会整理成 `corpus/<书名>/NNN.txt`，作者的朝代存进 `meta.json`。四库本没有标点，所以按页分段。

### 四库本：还原乾隆改译

1. `guoyujie` 提取《三史国语解》，得到"乾隆改译 → 旧译"的对照。乾隆所说的"满洲语、蒙古语释义"**不采用**，因为其中很多是附会。
2. `align A B` 把同一部书的两个版本逐卷比对，保留所有不同的、像音译的短片段。四库本的写法必须不出现在旧版本里。
3. 读 Kanripo 下载的书时，改译会自动还原，四库本写法以灰色小字保留。一个改译对应多个旧名时（"俄罗斯"既替换过斡罗思 *Orus*，也替换过兀鲁思 *ulus*），保持原样、画波浪线，悬停列出候选和次数。
4. 清代文献本来就用那些写法，**不还原**。

![四库本《元史》：巴图还原为拔都（ba'atur），四库本写法以灰色小字保留](docs/img/siku.png)

### 书站

`read 书的文件夹 -o 输出文件夹` 会生成：

- `index.html`：目录，每卷一条按语系着色的横条；
- 每卷一页，可以上下翻页；
- `names.html`：全部名字，按语系分组，附出现次数和各卷链接。

《旧唐书》两百零一卷约 6 秒生成。

### 发现工具

| 命令 | 作用 |
|---|---|
| `scan` | 一部书里所有像音译的名字的表格：次数、状态、原形、语系、首次出现的上下文 |
| `twins` | 读音相近、写法不同的名字，如 萧得里底 / 萧迭里得。这是待查清单，不是结论 |
| `propose`（实验性） | 把未知名字连同时代读音和一句上下文发给 LLM。被判为普通汉语词的会被过滤掉。提议的原形必须通过读音核验（≥ 0.60）才保留，显示为虚线。回答会缓存。**目前只用模拟回答测试过。** |

### 准确率

来自 `python yiming.py eval gold_pairs.tsv --corpus corpus`（见 `samples/eval.txt`）。

**汉字写法 vs 原形：** 词表里 166 对正确配对，对比 19,920 对错误配对。

| 门槛 | 正确认定能保留 | 错误认定会混入 |
|---|---|---|
| 0.55 | 78% | 4.0% |
| **0.60**（`propose` 默认） | 72% | 2.2% |
| 0.70 | 54% | 0.75% |

**写法 vs 写法：** 19 对已知异写，对比两万对随机名字。门槛 0.80 时，召回率 79%，每对的误报率 0.17%。

读音对得上只是过滤，不是证明。

## 局限

- **名字的语言是文化背景的证据，不是血统的证明。** 和其他线索（姓氏、籍贯、史书称"胡"）一致时，证据很强。在外族名字流行的时代就弱，比如元代汉人取蒙古名、僧人取梵语法名。
- **覆盖面取决于词表。** 《元史》里能检测出约 930 个音译名字，但人工词表只收了约 50 个。其余显示为浅灰，等 `propose` 或人工补充。
- **检测靠统计。** 唐代文献里有些汉语词（如"补阙"）会被误判。
- **四库本还原并不完美。** 会有漏掉的改译，比对偶尔也会把相邻的字带进名字。
- **`propose` 还没有用真实的 AI 回答测试过。**
- **词表里不少出处只写着 "standard"（通行认定）。** 应该逐步换成具体文献。
- **Kanripo 书目里列有《清史稿》，但正文并未公开。**

## 用到当前范围之外：需要改什么

### 现在的范围

- **文本：** 二十四史（hunterhug）和 Kanripo 上的书。都是汉至清的汉文史料。
- **读音：** `mc`、`om`、`qm` 三套方案，都从《切韵》推出。
- **名字：** 以内亚、南亚、西亚的名字为主，另有部分海上和欧洲名字，分为 12 个语系。

### 扩展清单

1. **文本。** 把纯文本放进 `corpus/<书名>/*.txt`，每段一行，`.html` 也可以。新来源需要写一个小转换器，可参考 `corpora.clean_mandoku`。
2. **时代。** 在 `origin.py` 的 `BOOK_SCHEME` 里加上书名，或在这部书的 `meta.json` 里写 `"scheme": "mc"`。
3. **读音。** 如果 `mc`、`om`、`qm` 都不合适，就新增一套方案：
   - 在 `yiming.py` 里扩展 `syllable()`（基于《切韵》的规则）或 `Phon.char_sylls()`（其他读音数据），让每个字返回（声母类、韵尾类、元音类）。
   - 把方案名加进命令行选项，以及 `origin.py` 的 `ERA`。
   - 新语言如有典型的音对应，加进 `yiming.py` 的 `SUB` 和 `INDEL`。
4. **名字。** 在 `lexicon.tsv` 里加条目，并写明真实出处。新的语系要加进 `origin.py` 的 `FAMILIES`，并在 CSS 部分给它一个颜色。
5. **写法。** 同名异写加进 `equivalence.tsv`。如果某个版本像四库本那样改过名字，就用 `align` 和未改的版本比对。
6. **检测。** 对新文本运行 `train --corpus 文件夹`。如果这个传统有自己常用的音译用字，加进 `origin.py` 的 `SEED_CHARS`。
7. **检查准确率。** 把这个领域的已知对应加进 `gold_pairs.tsv`，再运行 `eval`。只相信自己测量过的门槛。
8. **AI 提议（可选）。** 修改 `origin.py` 里的 `PROMPT`，描述新的领域。

### 具体场景

| 范围 | 需要改什么 |
|---|---|
| **朝鲜半岛的汉文史书**（三国史记、高丽史、朝鲜王朝实录） | 外族名字（女真、蒙古、日本）常由朝鲜文人音写。新增"朝鲜汉字音"方案（Unicode 的 Unihan 数据库字段 `kHangul` 提供读音；朝鲜汉字音的 *-l* 对应中古 *-t*），并新增朝鲜语、日本语等语系。 |
| **日本的汉文史书**（日本书纪、续日本纪等） | 朝鲜、阿伊努等名字用汉字表音，常类似万叶假名。新增"日本汉字音"方案（Unihan `kJapaneseOn`；*-tsu/-chi* ↔ *-t*，*-ku/-ki* ↔ *-k*）。 |
| **越南的汉文史书**（大越史记全书、钦定越史通鉴纲目） | 占婆、高棉、泰等名字。新增"汉越音"方案（Unihan `kVietnamese`；保留 *-t、-c、-p*），以及南亚语系、侗台语系等。 |
| **佛典**（CBETA） | 为 TEI XML 写转换器。东汉的早期译音（如"浮屠"）早于《切韵》，需要按已发表的构拟新增上古音或东汉音方案。 |
| **更早的时代**（《史记》《汉书》的匈奴、西域） | 同上，需要早于《切韵》的方案。源语言所知甚少，准确率会更低。 |
| **晚清、民国文献** | 西洋名字按官话，或按粤语、闽南语音写。新增拼音方案；南方文献可用粤语方案（Unihan `kCantonese`）。 |
| **其他被改过的版本** | 任何两个版本都可以用 `align` 比对。 |
