# 02 · 原理：程序怎么"听"出古音

这一篇写给想知道"为什么能这样做"的人。不需要编程知识，但需要一点耐心。

---

## 一、为什么不能用普通话比

用普通话读"禄山"是 lù-shān，和粟特语 Roxšan 几乎对不上。

但唐代人不说普通话。按《切韵》音系，"禄"读作大约 *luk*，带一个 -k 韵尾；"山"读作大约 *ʂɛn*。连起来是 *luk-ʂɛn*，和 Roxšan 的 r-o-x-š-a-n 就对得很整齐了：

| Roxšan | r | o | x | š | a | n |
|---|---|---|---|---|---|---|
| 禄山（中古音） | l | u | k | ʂ | ɛ | n |

中古汉语没有 r 声母，所以用 l 代替。x 是舌根擦音，用发音部位相近的 -k 韵尾代替。

**结论：比较音译名字，必须用写下这个名字时的读音，而不是今天的读音。** 这正是传统"对音研究"的思路。1923 年汪荣宝的《歌戈鱼虞模古读考》就是用梵汉对音来推古音；本工具反过来，用古音去找原名。

## 二、古音从哪里来

### 《切韵》

《切韵》是隋代陆法言在 601 年编成的韵书，北宋的《广韵》（1008 年）是它的增订本。书里每个字都有"音韵地位"：声母（如"來"母）、韵（如"東"韵）、声调（平上去入），以及开合、等第。

程序用的是 nk2028 项目整理的《切韵》系韵书数据，每个字都能查到音韵地位。比如：

```
python yiming.py key 禄山 --scheme mc
  禄  來一東入   →  声母 L，元音 u，韵尾 K
  山  生開山平   →  声母 S，元音 a，韵尾 N
```

### 简体字的处理

语料里简繁混用。程序查一个简体字时，用的是它**对应繁体字**的读音，例如"敌"用"敵"的读音。

原因是：很多简体字形恰好和《广韵》里某个毫不相干的古字同形。《广韵》里另有一个"敌"字，读音和"刮"相近。如果直接查简体字形，会得到错误的读音。早期版本就因此出过错。

## 三、三套古音方案

外族名字是在不同时代被记下来的，读音也要按时代选：

| 方案 | 适用 | 主要特点 |
|---|---|---|
| `mc`（中古音） | 汉至唐五代的史书 | 保留入声韵尾 -p -t -k；疑母读 ŋ- |
| `om`（近古官话，近似） | 宋辽金元明的史书 | 入声韵尾消失；疑母变零声母；日母近 r |
| `qm`（清代官话，近似） | 清代文献 | 在 om 的基础上，-m 韵尾并入 -n；声母保留尖团之分（见下） |

举例：明代的"瓦剌"。"瓦"是疑母字，唐代读 ŋwa，元明时已经读 wa，这才能对上 Oirat 开头的元音。

**尖团之分**：清代北京话里，"精"组和"见"组字在 i、ü 前已开始合流（今天的 j q x）。但清代给满文、蒙古文作汉字音写时，仍刻意区分"尖音"（精组 ts-）和"团音"（见组 k-）。1743 年的《圆音正考》就是为此编的。所以 `qm` 仍按《切韵》的声母来分尖团，而不用今天的普通话。

**程序怎么选方案**：

1. 先查书名对照表（`origin.py` 里的 `BOOK_SCHEME`，收录了二十四史和几十部常用书）。按**史料的时代**，而不是编者的时代来定。例如《明史》是清人编的，但史料来自明代，所以用 `om`；《旧唐书》是后晋人编的，用 `mc`。
2. 表里没有的书，用 `fetch` 下载时记在 `meta.json` 里的**作者朝代**。
3. 都没有，就用 `mc`。

**时代过滤**：词表里每一条都标着它最早写法的时代。**晚出的条目不会在早期的书里匹配**。例如"古里"指 Calicut 是明代的事，所以在《旧唐书》里遇到"古里"不会标成 Calicut。

`om` 是从《切韵》推出来的**近似**，不是对《中原音韵》的真正构拟。

## 四、把名字变成"音类骨架"

程序不比较精确的音值，因为那本身就有争议。它把每个音节归成粗略的类别：

| 类 | 包括的声母 | 例字 |
|---|---|---|
| P | 帮滂並（唇塞音） | 拔 伯 不 |
| M | 明 | 木 马 默 |
| T | 端透定、知徹澄 | 帖 脱 达 |
| N | 泥孃 | 那 纳 |
| C | 精清從、莊初崇、章昌常船（塞擦音） | 赤 察 只 |
| S | 心邪、生俟、書（擦音） | 速 撒 失 |
| K | 見溪羣 | 哥 可 阙 |
| G | 疑（ŋ） | 瓦（唐） |
| H | 曉匣 | 忽 哈 颉 |
| L | 來 | 鲁 剌 禄 |
| R/J | 日 | 儿 |
| （无） | 影云以（零声母） | 阿 亦 斡 |

元音只分三类：a、i、u。韵尾分为 -p -t -k -m -n -ŋ，或者没有。

于是"禄山"变成 `LuK SaN`，Roxšan 变成 `RuH SaN`。

## 五、编进程序的对音习惯

音译不是随意的，有规律可循。程序把几条公认的规律编进了打分规则，让这些"差异"几乎不扣分：

| 规律 | 例子 |
|---|---|
| l 和 r 互代（汉语没有 r） | 禄山 = **R**oxšan |
| 舌根音 k 和 h/x 互代 | 禄山的 -k = Ro**x**šan 的 x |
| 唐代用 -t 韵尾对译外语的 -r/-l | 阙 kʷɐt = **kül**，突 = **Tür**k |
| 唐代西北方音的鼻音声母去鼻化：明母近 b、泥母近 d、疑母近 g | 默啜 = **B**äg Čor |
| 外语词尾辅音常被省略 | 颉利 = Illi**g** |
| 塞擦音和擦音相近 | 赤 ~ 失 |

## 六、打分：加权编辑距离

两个骨架之间的差异，用"加权编辑距离"计算：把一串变成另一串，最少要改动多少，每种改动的代价不同。

- 声母类别不同：扣 1 分。符合上面那些规律的替换只扣 0.2 到 0.3 分。
- 元音不同：只扣 0.25 分（元音最不可靠）。
- 多一个或少一个音：扣 0.3 到 1 分。

最后换算成 0 到 1 的相似度：1 表示完全对上，0 表示毫无关系。

**多音字**（如"不"有三个读音）会把每种读法都试一遍，取最高分。

例：`禄山` 与 `Roxšan`，只有 L↔R（0.2）和 K↔H（0.3）两处差异，相似度约 0.88。

## 七、怎么判断一个词"像音译"

史书里绝大部分文字是汉语，程序得先找出**哪些字串像音译**。

办法是统计。程序从语料本身学习：

- **音译名字里常用的字**：从辽金元史的"本名××""又作××"，以及契丹、女真复姓后面的名字里统计出来，例如忽、兀、孛、斡、秃、帖。
- **普通汉文和汉人名字里常用的字**：例如之、以、而、忠、良。

对每个字，程序计算"它出现在音译名里的可能性"和"出现在普通文字里的可能性"之比。一串连续的高分字，就被标为"像音译"。

最常用的 120 个字（如不、之、也）虽然也出现在名字里（不花、也先），但因为太常见，它们的分数一律压到中性，不能单独成为证据。

**这个方法在《元史》上效果好，在唐代史书上误判较多**，因为唐代汉人名字和官职也常用这类字（如"补阙""金吾卫"）。所以需要 AI 那一步再过滤一遍。

## 八、准确率

这些数字来自 `samples/eval.txt`，可以自己运行 `eval` 重现。

### 汉字写法 vs 原形（用来核验 AI 提议）

词表里有 166 对正确的"汉字写法–原形"，另外把每个写法和**别的**词条的原形配对，得到 19,920 对错误配对：

| 门槛 | 正确的能保留 | 错误的会混进来 |
|---|---|---|
| 0.55 | 78% | 4.0% |
| **0.60（默认）** | 72% | 2.2% |
| 0.70 | 54% | 0.75% |

意思是：门槛定在 0.60 时，真正正确的原形有 72% 能通过；随便一个错误的原形只有 2.2% 会通过。门槛越高越严格，但也会错杀更多正确的。

### 异写 vs 异写

用 19 对已知的异写（如 速不台/雪不台、斡啜/兀术）做测试，另外随机抽 20,000 对不相关的名字：门槛 0.80 时，能找到 79% 的真异写，随机名字对被误判的比例是 0.17%。

0.17% 听起来很小，但一本书里有两千个名字，就有约两百万对组合，误判的会有几千对。**所以 `twins` 的结果只是待查清单，不是结论。**

## 九、四库本改译是怎么还原的

两个来源互相补充：

1. **《钦定辽金元三史国语解》**：乾隆君臣自己编的改译对照。每条的格式大致是"新译（……卷几作旧译）"。程序逐条提取，并去掉跟在旧译后面的说明文字，如"睿宗名""山名""併改"。

   注意：《国语解》里对名字的"满洲语、蒙古语释义"多是附会（把契丹、女真名字硬解成满语词），**程序不采用这些释义**，只用它记录的写法对应。
2. **版本对齐**：同一部书的中华本和四库本逐卷比对（逐字的最长公共子序列算法）。两个版本绝大部分文字相同，不同的地方大多就是被改的名字。程序只保留这样的差异：
   - 看起来像音译；
   - 并且四库本的写法**不出现在中华本里**。否则它只是普通的异文，不是改译。

   在《元史》本纪上，这样得到约 3,600 对。

**一对多怎么办**：如果一个新写法对应几个旧名，程序按出现次数加权。第一名要至少是第二名的三倍才采用，否则保持原样并标波浪线。宁可不改，也不改错。

## 十、和学术传统的关系

这个工具做的事，是历代学者一直在手工做的：

- **对音研究**：用汉译佛经、外语转写来推定汉字古音，例如汪荣宝的梵汉对音研究。罗常培的《唐五代西北方音》（1933）利用敦煌汉藏对音材料，揭示了本工具用到的"鼻音声母去鼻化"现象。
- **名物考订**：伯希和（Paul Pelliot）等人逐个考证西域、北族名字的原形。蒲立本 1955 年讨论安禄山背景时，就用到了"禄山 = Roxšan"。
- **发现一人两传**：清代赵翼的《廿二史札记》已经指出《元史》把速不台、雪不台当作两个人，各立了一篇传。
- **反面教训**：乾隆时编《钦定辽金元三史国语解》，把辽金元三史的译名按满语、蒙古语"改正"了一遍。结果四库本里的名字反而更难辨认。这就是为什么 yiming **永远保留原书写法**。

程序能做的，是把前人一条一条做的工作，放到几千万字的规模上，并且每一条都标明可信程度。
