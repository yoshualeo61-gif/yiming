# 03 · 词表编写规范

yiming 靠两张表工作。它们是纯文本表格，每一列之间用 **Tab 键**（制表符）隔开。

| 表 | 回答什么问题 | 例子 |
|---|---|---|
| `lexicon.tsv`（原形词表） | 这个汉字名字**原来是什么** | 禄山 → Roxšan，粟特语 |
| `equivalence.tsv`（异写统一表） | 这几个写法**是不是同一个名字**，统一显示成哪个 | 雪不台、速不台 → 速不台 |

一个名字可以同时出现在两张表里。

---

## 一、用什么软件编辑

**推荐**：VS Code、Notepad++、Sublime Text，或 Mac 自带的"文本编辑"（要切换到纯文本模式）。

**小心使用 Excel**：Excel 打开 TSV 时可能搞乱编码或自动改格式，比如把 "1-2" 改成日期。如果一定要用，请"导入数据"，并选择 UTF-8 编码和 Tab 分隔，保存时也选"制表符分隔的文本"和 UTF-8。

**检查 Tab**：在 VS Code 里用"显示空白字符"功能，Tab 会显示成 →。空格不行，必须是 Tab。

以 `#` 开头的行是注释，程序会忽略。

---

## 二、`lexicon.tsv`：原形词表

### 每一列

| 列 | 必填 | 说明 | 例 |
|---|---|---|---|
| `id` | ✅ | 英文或拼音的唯一编号 | `roxshan` |
| `original` | 建议 | 原语言形式，用学术通行的拉丁转写；不知道就留空 | `Roxšan` |
| `language` | ✅ | 具体语言 | `Sogdian` |
| `family` | ✅ | 语系，**只能填**下面 8 个之一 | `Iranian` |
| `gloss` | 建议 | 意思或简短说明（英文或中文均可） | `"bright, light"` |
| `forms` | ✅ | 汉字写法，多个用 `\|` 隔开，简繁都可以 | `禄山\|轧荦山` |
| `kind` | ✅ | 类型：person / name-element / title / ethnonym / place / dynasty / term | `name-element` |
| `scheme` | ✅ | **最早**那个写法的时代：`mc`（汉唐）、`om`（宋辽金元明）或 `qm`（清）。程序不会在更早时代的书里匹配这一条 | `mc` |
| `source` | ✅ | 出处：著作、作者和年份，或 "standard"（教科书级常识） | `Pulleyblank 1955` |
| `status` | ✅ | `attested`（已查证）或 `llm-proposed`（AI 提议） | `attested` |
| `entity` | 可选 | 同一事物的不同名称，填同一个编号（见下文） | `ottoman` |
| `exclude` | 可选 | 在这些字串里**不算**这个名字，多个用 `\|` 隔开 | `鲁迷失` |

**family 只能填这 12 个**：`Iranian`、`Turkic`、`Mongolic`、`Para-Mongolic`、`Tungusic`、`Tibetic`、`Indic`、`Dravidian`、`Semitic`、`Austronesian`、`European`、`Other`。填错会被当作 `Other`。

### 一条完整的例子

加入蒙古帝国的都城"哈剌和林"（Qaraqorum）：

```
qaraqorum	Qaraqorum	Mongolic / Turkic	Mongolic	capital of the Mongol Empire	哈剌和林|和林	place	om	standard	attested		
```

最后两列（entity、exclude）留空，但**它们前面的 Tab 要保留**。

加完后运行 `read` 读一卷含这个名字的文字，检查它有没有正确显示。

## 三、四条原则

### 原则 1：只收有出处的

`source` 不能空着。拿不准的认定不要写 `attested`。宁可让这个名字保持浅灰色的"原形未知"，也不要给读者一个错误的答案。

### 原则 2：同名异写 ≠ 同实异名

这是最容易混淆的一点：

- **同名异写**：同一个**名字**，用了不同的汉字。例如：斡亦剌 / 瓦剌 都是 Oyirad。
  → 放进同一条的 `forms`，或放进 `equivalence.tsv` 统一写法。
- **同实异名**：同一个**东西**，用了完全不同的**名字**。例如奥斯曼帝国：鲁迷（Rūm，"罗马"）/ 控噶尔（Khünkär）/ 土耳其（Türkiye）。
  → **分成不同的词条**，每条有自己的 original，用同一个 `entity` 编号把它们连起来。
  → 阅读页面上它们互相提示"同一实体也写作……"，但**不会被统一成一种写法**，因为它们本来就是不同的名字，各有来历。

还有一种情况：撒马尔罕在元代也叫"寻思干"（突厥语 Semizkent，"肥沃的城市"）。这是另一个名字，所以**不能**放进撒马尔罕的 `forms`。

### 原则 3：遇到误伤就用 `exclude` 排除

程序按字面匹配，所以会误伤。实际碰到过的例子：

| 名字 | 误伤场合 | exclude 填 |
|---|---|---|
| 鲁迷（Rūm） | 《元史》人名"脱鲁迷失""忽都鲁迷失"，其中"迷失"是突厥语名字后缀 | `鲁迷失` |
| 海牙（qaya，"岩石"） | 《明史》地名"沙鹿海牙"（Shāhrukhiyya） | `沙鹿海牙` |
| 浮屠（Buddha） | "七级浮屠"里的浮屠指佛塔 | `级浮屠\|浮屠寺\|…`（写在 equivalence.tsv） |

**找误伤的方法**：生成阅读页面后，看页面底部的索引表，把出现次数多的名字逐个点开核对几处。

### 原则 4：AI 的提议要查证后才转正

`propose` 生成的 `lexicon_proposed.tsv` 里，`source` 一栏写的是 AI 给出的出处，并注明"source not checked"。转正步骤：

1. 去图书馆或 CNKI 查证这个出处**真的存在**，并且**真的这样说**。
2. 把这一行剪切到 `lexicon.tsv`。
3. `status` 改成 `attested`，`source` 改成你核实过的出处，`id` 去掉 `llm-` 前缀。

## 四、`equivalence.tsv`：异写统一表

### 每一列

| 列 | 说明 | 例 |
|---|---|---|
| `id` | 唯一编号 | `subutai` |
| `canonical_zh` | **统一显示的写法** | `速不台` |
| `latin` | 拉丁转写（显示在悬停框里） | `Sübe'etei` |
| `variants` | 所有写法，`\|` 隔开，**包括统一写法本身** | `速不台\|雪不台` |
| `foreign` | 其他语言中的形式（说明用） | `mn Ойрад; ru Ойраты` |
| `scheme` | `mc` 或 `om` | `om` |
| `confidence` | high / medium / review | `high` |
| `note` | 说明 | `元史一人两传` |
| `exclude` | 同 lexicon | |

### 统一写法选哪个？

选一条规则，**全表都用它**。自带的表用的规则是"二十四史里最常见的写法"。你也可以改成"现代学界通行写法"（例如卫拉特），但不要这条用这个规则、那条用那个规则。

### 从 `twins` 的结果里补充

```
python yiming.py twins --corpus corpus --books 辽史,金史 --emit-table 候选.tsv
```

`候选.tsv` 的格式和 equivalence.tsv 一样，每行是一组读音相近的写法，`confidence` 为 `review`。逐行判断：

- 是同一个名字 → 复制到 `equivalence.tsv`。
- 只是读音碰巧相近（例如 耶律乙辛 / 耶律义先，这是两个人，名字也未必相同）→ 丢弃。
- 标了 `check: chained cluster` 的，是一串名字被链式连在一起，要特别小心拆开看。

---

## 五、改完之后

1. 运行 `read` 生成一卷含新名字的页面，确认显示正确。
2. 运行 `eval`，确认准确率没有明显下降。
3. 如果你在 `gold_pairs.tsv` 里也加了新的已知异写对，`eval` 会一并测试。

## 六、四库本改译表（一般不用手改）

`equivalence_siku.tsv` 和 `equivalence_aligned_*.tsv` 由程序生成，格式和 `equivalence.tsv` 一样，多了两列：

- `scope`：适用范围。读《元史》时优先用"元"和"元史"的行。
- `count`：对齐时这个改名出现的次数，用来在一对多时加权。

**给另一部书做对齐**（例如《金史》）：

```
python yiming.py fetch 金史 --corpus corpus --name 金史_四库
python yiming.py align corpus/金史 corpus/金史_四库 -o equivalence_aligned_金史.tsv
```

文件名以 `equivalence_aligned` 开头即可，程序会自动读入。

发现某一行明显错了（常见的是对齐把"之""及"之类的字带了进来，如"拔都及"），直接删掉那一行就行。
