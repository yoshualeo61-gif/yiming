# 04 · 七个练习

从最简单的"读一篇传"开始，到最后做一个小研究。每个练习都写了要用的命令，也写了要带着什么问题去看。

练习 1 到 4 不需要 API key。练习 5 需要。

---

## 练习 1：读《安禄山传》

```
python yiming.py read corpus/旧唐书/列传/第一百五十章-卷一百五十-原文.html -o 安禄山传.html
```

打开页面，回答：

1. "禄山"上方写的是什么？悬停后，它是什么语言、什么意思？
2. 第一段有一句"本无姓氏，名轧荦山"。"轧荦山"被标成了什么？为什么它和"禄山"是同一个名字？可以用 `python yiming.py match 轧荦山 Roxšan` 看看。
3. 悬停时出现了关于"安"的提示。昭武九姓里的"安"对应哪座城市？这个提示为什么只能算"提示"？
4. 同一卷里还有**史思明**。找到"本名窣干"这句（可以用 `find 窣干`）。"史"也是昭武九姓之一，对应哪座城市？"窣干"被标注了吗？如果没有，你觉得它可能是什么来历？（这个问题没有标准答案。可以查蒲立本和荣新江的相关研究。）
5. 史书说安禄山"通六蕃语，为互市牙郎"，又说他的母亲是"阿史德氏，亦突厥巫"。他的粟特名字说明了他什么样的文化背景？哪些是名字说明不了的？（参考 [05-注意事项与常见问题](05-注意事项与常见问题.md) 第一节的强弱表。）

## 练习 2：《明史》里的"鲁迷"

```
python yiming.py find 鲁迷 --corpus corpus --books 明史
python yiming.py read corpus/明史/列传/第二百二十章-卷二百二十-原文.html -o 明史西域.html
```

1. 悬停在"鲁迷"上：它的原形是什么？"Rūm"这个词本来是什么意思？
2. 悬停框里写着"同一实体也写作 控噶尔、土耳其"。为什么这三个名字**不能**像"雪不台/速不台"那样统一成一种写法？
3. 1957 年周宏涛、许卓山考订《明史》中鲁迷国**五次**朝贡的记载。用 `find` 的结果，自己找出这几次朝贡各在哪一年。
4. 嘉靖三年鲁迷贡狮子，嘉靖三年是公元哪一年？那时奥斯曼的苏丹是谁？（提示：苏莱曼一世 1520–1566 年在位。）
5. 同一卷里还有"哈烈""哈密""土鲁番"。它们各被标成了什么？
6. 页面里有很多浅灰色点线的名字，随便挑三个，你能查到它们的原形吗？

## 练习 3：给《旧唐书》的外族名字做一张表

```
python yiming.py scan --corpus corpus --books 旧唐书 -o 旧唐书名字.tsv
```

用 Excel 或 WPS 打开（导入时选 UTF-8 和 Tab 分隔）：

1. 按"语系"一列筛选。哪个语系的名字出现最多？你觉得为什么？
2. 筛选"status = unknown"的行，看前 30 个。哪些确实是外族名字（如颉利、默啜、沙陀）？哪些其实是汉语词被误判了（如补阙）？数一数误判的比例。
3. 这就是需要 AI 过滤的原因（练习 5）。你判断"是不是汉语词"时，依靠的是什么线索？

## 练习 4：辽金史里的"双胞胎"名字

```
python yiming.py twins --corpus corpus --books 辽史,金史 -o twins.tsv --emit-table 候选.tsv
```

打开 `twins.tsv`，找到这几组：

- 萧得里底 / 萧迭里得 / 萧得里特
- 耶律棠古 / 耶律唐古
- 耶律挞不也（辽史）/ 移剌塔不也（金史）

对每一组：

1. 读一读 `snippet` 一栏的开头，或者用 `find` 找到原文完整地读。
2. 判断：只是**名字相同**（同名的不同人），还是**同一个人**被写了两次？
3. 写下你的证据：年代、官职、父祖、事迹。
4. 耶律挞不也和移剌塔不也：先查"耶律"和"移剌"是什么关系（悬停在"移剌"上就能看到），再判断。

这就是"互见"的基本功：**程序负责找出候选，人负责判断。**

## 练习 5：让 AI 补充《元史》的名字（需要 API key）

```
python yiming.py propose --corpus corpus --books 元史 --top 30 --dry-run
python yiming.py propose --corpus corpus --books 元史 --top 30
python yiming.py read corpus/元史/本纪/第三章-卷三-原文.html -o 宪宗本纪.html
```

1. 对比运行前后的页面：哪些浅灰色点线变成了有颜色的虚线？
2. 打开 `llm_cache.json`，找一个 `"kept": false` 的候选。它为什么被读音核验淘汰了？用 `match` 验证一下。
3. 打开 `lexicon_proposed.tsv`，挑 3 条去查证 `source` 里的出处。出处真的存在吗？真的是这样说的吗？
4. 查证属实的，按 [03-词表编写规范](03-词表编写规范.md) 转正到 `lexicon.tsv`。

## 练习 6：自己加一条词条

目标：让"哈剌和林"（蒙古帝国都城 Qaraqorum）在阅读页面上显示出来。

1. 用 `find 哈剌和林 --corpus corpus` 看看它出现在哪里。
2. 按 [03-词表编写规范](03-词表编写规范.md) 第二节的例子，在 `lexicon.tsv` 里加一行。
3. 对含这个名字的卷运行 `read`，检查显示是否正确。
4. 进阶：再找一个你感兴趣的名字（比如某个突厥可汗的称号），查到可靠出处后加进去。

## 练习 7：找一个误伤，并修好它

1. 任选一卷生成阅读页面，拉到页面底部看索引表。
2. 找一个被**标错**的名字，也就是实线标注，但在某处其实不是这个意思。可以参考 03 文档里"鲁迷失""沙鹿海牙"的例子。
3. 在对应词条的 `exclude` 一栏加上排除字串。
4. 重新生成页面，确认改好了，而且没有误伤其他地方。

## 练习 8：四库本《元史》和中华本对照

直接用浏览器打开 `samples/元史四库本_本纪/index.html`。这是从 Kanripo 下载的四库本《元史》本纪 47 卷，已经生成好的书站。

1. 打开卷三。"莽赉扣""图类""巴齐玛克"各被还原成了什么？
2. 找到"征俄罗斯部"。为什么"俄罗斯"是**波浪线**？悬停看候选。按上下文，这里应该是哪一个？（提示：拔都西征的对象。）
3. 打开名字索引。伯颜在四库本里有几种写法？
4. 想一想：乾隆为什么要改这些名字？改译对后人读史造成了什么影响？（可以查"三史国语解"的研究。）

## 练习 9：《大唐西域记》里的梵语名字

```
python yiming.py fetch 大唐西域记 --corpus corpus --juan 1
python yiming.py read corpus/大唐西域記/001.txt -o 西域记卷一.html
```

1. 阿罗汉、菩萨、释迦、婆罗门各被标成了什么？
2. "飒秣建"是哪座城市？它和《明史》的"撒马儿罕"是什么关系？
3. 页面上有不少浅灰点线的名字，如"迦腻色迦"。词表里有"迦腻色伽"（Kaniška），二者只差一个字。用 `match` 比较一下它们。
4. 这一卷用的是哪套读音方案？为什么？

## 进阶：一个小研究题目

选一部史书，用 `scan` 统计其中外族名字的语系分布；再换一部不同时代的史书做同样的统计。比较两者，写一页说明：

- 哪些语系的名字变多了，哪些变少了？
- 这反映了什么历史变化？（例如，唐代粟特人的活跃，元代色目人的进入。）
- 你的统计里，有多少是"原形未知"？这对你的结论有什么影响？

最后一问最重要：**知道自己的数据有多少不确定，是做研究的第一步。**
