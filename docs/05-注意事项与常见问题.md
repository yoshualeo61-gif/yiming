# 05 · 注意事项与常见问题

## 第一部分：这个工具**不能**说明什么

### 1. 名字能说明多少文化背景

名字是历史学里判断文化背景的**常用证据**。粟特研究（如荣新江、魏义天 de la Vaissière）辨认入华粟特人，很大程度上就是靠名字和姓氏。所以一个粟特语名字，本身就是这个人与粟特文化有关的真实证据。

证据的强弱取决于情境：

| 强度 | 情形 | 例子 |
|---|---|---|
| **强** | 名字和其他线索一致：昭武九姓姓氏、籍贯、史书称"胡"、家族成员也用同类名字 | 安禄山：粟特名 + 安姓 + 营州杂胡 + 通六蕃语 |
| **中** | 名字单独出现，但时代、地域相符 | 唐代河西一位名字是粟特语的军将 |
| **弱** | 在某种外族文化流行的时代，名字可能只是风尚、宗教或政治身份 | 元代汉人取蒙古名；突厥贵族取粟特名；僧人取梵语法名 |

**名字说明的是"他身处哪种文化环境"，这一点通常可靠；"他的祖先是哪族"则需要更多证据。** 安禄山两方面都是好例子：他的名字确实反映了他的粟特文化环境，而他的母亲是突厥人。

所以阅读页面标的是名字的语言。至于据此能推出多少，要结合上面的情境判断。

### 2. 实线也可能有争议

实线表示"有学术出处"，不表示"定论"。不少认定本身就是构拟，例如 默啜 = Bäg Čor。重要的论点请回到 `source` 一栏的原始研究去看。

### 3. 虚线是线索，不是结论

虚线来自 AI 提议，只通过了读音核验，**出处没有核实**。AI 可能编造出处，而读音核验挡不住"读音碰巧对得上"的错误提议。

### 4. 浅灰点线可能不是外族名字

音译检测靠统计。在唐代史书里，程序常把汉语官职、人名误判成音译，比如"补阙"。运行 `propose` 后，AI 会把这些过滤掉。

### 5. 语料的限制

- hunterhug 语料只有二十四史，其中《元史》没有列传。其他书可以用 `fetch` 从 Kanripo 下载，但那多是四库本（见第 6 条）。

### 6. 四库本还原并不完美

- 《国语解》和版本对齐都有漏网的改名。它们会以浅灰点线显示（"原形未知"）。
- 乾隆有时把几个旧名改成同一个新写法。程序遇到这种情况会保持原样、标波浪线，**需要你按上下文判断**。
- 对齐偶尔会把相邻的字带进名字里（如"拔都及"），或者切掉名字的一部分。
- 恢复出来的旧译，其字形取自中华本；程序会按所在段落转成繁体或简体，但个别字可能不理想。
- Kanripo 的四库本**没有标点**，也没有分段，所以程序按页分段，读起来比中华本吃力。无法用 Unicode 表示的字显示为"〓"。

### 7. 不是所有书都能下载

- Kanripo 书目里列有《清史稿》，但正文没有公开。清代正史需要另找来源（任何按"书名/卷.txt"放好的纯文本都能读）。
- 清代读音方案 `qm` 是近似的。

### 8. "没被标出来"不等于"不是外族名字"

检测有漏网之鱼。词表之外、字面又不像音译的名字，比如用汉语常用字写成的"史思明本名窣干"，程序可能完全看不出来。

## 第二部分：常见问题（按你看到的现象查）

### 输入 `python` 后提示"不是内部或外部命令"（Windows）

安装 Python 时没有勾选 "Add python.exe to PATH"。二选一：

- 试试用 `py` 代替 `python`：`py yiming.py -h`
- 或重新运行 Python 安装程序，选 "Modify"，勾选添加到 PATH。

### Mac 上提示 `command not found: python`

用 `python3` 代替 `python`。

### 提示 `No such file or directory` / 找不到文件

- 确认终端当前在 `yiming` 文件夹里。Windows 用 `dir`、Mac 用 `ls` 看看，应该能看到 `yiming.py`。
- 确认语料文件夹叫 `corpus`，并且和 `yiming.py` 放在同一层。
- 文件名很长，不要手打。先用 `find` 命令找到路径再复制；或者输入开头几个字后按 **Tab 键**自动补全。

### 屏幕上出现乱码或 `UnicodeEncodeError`（Windows）

程序已经做了处理。如果还出现，先运行：

```
chcp 65001
```

再运行 yiming 命令。

### 页面上某个名字没有上方的小字

说明它不在词表里，AI 也还没补充过。可以：

- 运行 `propose` 让 AI 补充（练习 5）；
- 自己查到出处后加进 `lexicon.tsv`（练习 6）。

### 页面上浅灰点线太多，看着乱

- 加 `--unknown-mean 2.5`（数字越大越少），或者
- 加 `--known-only`，只显示词表里的名字，或者
- 运行 `propose`，让 AI 把误判的汉语词过滤掉。

### `propose` 报错

| 报错里有 | 原因 | 解决 |
|---|---|---|
| `No module named 'anthropic'` | 没装库 | `pip install anthropic` |
| `authentication` / `api_key` | 没设置 key，或 key 有误 | 按 01 文档第八节重新设置。每次新开终端都要设置 |
| `rate limit` | 请求太快 | 等一会儿再运行。已经回答过的有缓存，不会重复收费 |
| `model` 相关 | 模型名不可用 | 用 `--model-name` 换一个可用的模型 |

### 读整本书太慢，页面打不开

整本《元史》有几百万字。改为一次读一卷：`read corpus/元史/本纪/第三章-卷三-原文.html`。

### 页面字体不好看

安装思源宋体（Noto Serif SC 或 Noto Serif TC）后刷新页面，页面会自动使用它。

### 我和别人的结果不一样

检查这几个文件是否相同：

- `lexicon.tsv`、`equivalence.tsv`：词表不同，结果自然不同；
- `llm_cache.json`、`lexicon_proposed.tsv`：AI 的回答；
- `foreign_model.json`：运行过 `train` 会改变音译检测的结果。

### 我想恢复原样

重新解压 `yiming.zip`。`corpus` 文件夹可以直接复制过去，不用重新下载。

## 第三部分：想反馈或改进

发现误伤、漏标或错误认定，最好记下三样东西：

1. 书名和卷；
2. 原文那一句；
3. 你认为正确的是什么，**以及出处**。

有了这三样，任何人都能复核并修正词表。这也是做学问的基本格式。
